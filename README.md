#  Password Generator &  Student Predictor

##  About the Project
This repository contains two mini projects:
1. A Password Generator web application
2. A Student Performance Predictor using R and Shiny

---

##  Password Generator (Web App)
- Built using HTML, CSS, JavaScript
- Generates strong and secure passwords
- Includes options for uppercase, lowercase, numbers, and symbols
- Runs in browser

---

##  Student Performance Predictor (R + Shiny)
- Built using R, Shiny, and ggplot2
- Uses Linear Regression to predict marks based on study hours
- Interactive web application
- Displays prediction and graph

---

##  Tech Stack
- HTML, CSS, JavaScript
- R Programming
- Shiny
- ggplot2

---

##  How to Run

### Password Generator
- Open `index.html` in browser

### Student Predictor (Shiny App)
```r
